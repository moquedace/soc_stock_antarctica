# Visual Identity Notes

This repository supports an Antarctic soil carbon paper. The presentation
should feel polar, precise, and article-first.

## Direction

- Use institutional identity first, followed by a thematic Antarctic banner.
- Keep all scientific claims anchored to the article.
- Avoid remote preview images in the README; use local assets to prevent broken
  image icons.

## Palette

| Role | Hex | Use |
| --- | --- | --- |
| Polar night | `#0b1620` | Banner background and technical tone. |
| Ice blue | `#8fb8de` | Primary accent and DOI/data emphasis. |
| Deep ocean | `#365f7f` | Map mass and secondary emphasis. |
| Snow | `#f8fbfd` | Primary text over dark background. |
| Warming orange | `#d97642` | Climate warming and SOC point accent. |

## Assets

- `img/terrantar_labgeo.png`: institutional identity.
- `img/readme_banner.svg`: custom Antarctic SOC banner.
- `img/soc_stock_points_map.png`: local sample distribution preview.
- `img/pred_obs_ocs_example.png` and `img/imp_ocs_0_5_example.png`: model
